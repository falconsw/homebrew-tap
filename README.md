# Falcon Software Homebrew Tap

## Süpürücü

Menu bar storage reclaimer and app uninstaller for macOS 14+.

```sh
brew install --cask falconsw/tap/supurucu
```

Update with `brew upgrade --cask supurucu`, remove with `brew uninstall --cask supurucu`
(add `--zap` to also delete its preferences and caches).

Downloads: https://github.com/falconsw/homebrew-tap/releases

## Dürücü

Archive browser for macOS 26+: look inside ZIP/7Z/RAR/TAR before extracting, extract what you need,
add or remove files, and create ZIP (AES-256), 7Z, TAR.GZ and TAR.XZ archives.

```sh
brew install --cask falconsw/tap/durucu
```

Source: https://github.com/falconsw/durucu

## Folderpad

App folders in the Dock for macOS 26+, now that Launchpad is gone: gather apps into groups that sit in
the Dock with Launchpad-style icons, and manage every folder after the Dock's divider.

```sh
brew install --cask falconsw/tap/folderpad
```

Source: https://github.com/falconsw/folderpad

## Kestirme

Keyboard shortcut overlay for macOS 14+: hold ⌘ to see every shortcut of the frontmost app, read live
from its menus; press ⌥⌘K to pin it, search, and run commands. Interface in Turkish.

```sh
brew install --cask falconsw/tap/kestirme
```

Source: https://github.com/falconsw/kestirme

## Launchset

Menu bar app for macOS 14+ that opens sets of apps in one click: group the apps you always open together into
routines (Morning, Work, Evening…) and launch each set from a colored card, then it quits out of your way.
Light and dark mode, Turkish and English.

```sh
brew install --cask falconsw/tap/launchset
```

Source: https://github.com/falconsw/launchset
